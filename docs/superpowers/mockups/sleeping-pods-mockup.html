A rest section for a round platform

Design ideas only (a mockup, nothing here is connected to real agents). Rule for every idea: a pod, bed or hatch is occupied only by a real agent that really is asleep. Working and waiting agents keep their desks and the spotlight; an agent that was never seen running ("standing by") gets an empty, dark spot.
What went wrong with the docks: they face the core, and the default camera looks in from the front. So on the near half of the platform you see their backs (dark boxes, robot hidden), and they were tall and heavy. New rules: (1) look right from every side, so nothing depends on which way it faces; (2) keep it low or flush so it doesn't hide things; (3) the robot must be visible from the default angle, with no glass box to look through.

    How it stays honest. The section is a read-only picture of the roster: one place per agent that exists, filled when its state is idle (from the transcripts, not invented). The walk back to the desk plays only when the real state changes to working. If there are more sleepers than places, the last one shows "+N more", like the bays. A demo project shows no sleepers, because it has no real agents behind it. Any bar or light on a bed means a real fact: the time since the agent's last activity.
