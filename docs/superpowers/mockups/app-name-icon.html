A name and an icon for the agent panel

Four ideas. Each is shown big, at the small sizes Windows uses, in the window's title bar and on the taskbar. All icons are drawn in code from the Orbit idea, so they match the panel and the 3D solar system.

The name also becomes the window title (with the waiting count, for example "Perigee (2 waiting)"); the widget's window is found by that title, so the name is set in one place in the code. I have not checked trademarks; a quick search before publishing is wise.
