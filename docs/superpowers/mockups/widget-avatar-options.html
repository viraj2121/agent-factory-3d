Options for the little figures in the widget

Design mockup. Each option shows the three states: working, waiting for you and resting, big and at the real widget size. The coloured detail (shirt, collar, pot, glow) is the agent's tool colour; here Claude Code coral.
Honest notes. These are drawn and animated in 2D (SVG), which is very light: a widget that runs all day costs almost nothing, unlike the 3D robots. Any option can be made in 3D later if you want. The figure only shows the state the service already infers (working / waiting / resting); it does not mean the agent is literally typing.
