# Glossary

| Word | Meaning |
| --- | --- |
| **Agent** | A coding agent that exists in a project: an agent file, a session, or a subagent run. |
| **Session** | One run of an agent tool (for example Claude Code) in a project folder. |
| **Subagent** | A helper agent a session started (Explore, general-purpose, or one defined in an agent file). |
| **Roster** | The list of every agent that exists in a project, working or not. |
| **Working** | The agent wrote something very recently (inferred from timing). Shown with lit eyes and a green gem. |
| **Waiting for you** | The agent stopped and needs a person (inferred). Amber tag, waving, amber gem. |
| **Idle / asleep** | Ran lately and is quiet. Dim eyes and z z Z. |
| **Standby** | Defined in an agent file but never seen running. Eyes off. |
| **Bay** | One of the three open stations: Planning, Development & Integration, Review & QA. Sleeping agents rest in the rest pods round the core. |
| **Seat** | One of three desks in a bay. More agents than seats show as `+N more`. |
| **Hall** | The round hub of one project. |
| **System** | The solar system level above the hall, one planet per project. |
| **Harness** | The setup around the agents: CLAUDE.md or AGENTS.md, skills, subagent files, slash commands, hooks, plugins. |
| **MCP server** | A tool server an agent can call, listed per project. |
| **Hook** | A small call (`POST /api/hook`) that lets any other agent report itself. |
| **Picture mode** | `H`: every bar, panel and label fades out, leaving only the picture. |
| **Lite** | The cheapest quality level, for computers with no graphics card. |
| **Demo data** | Made-up data for the look test. Always labelled. |
