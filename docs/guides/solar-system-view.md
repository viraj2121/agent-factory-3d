# The solar system

Press `G` (or the System button) to fly up from the hall. Every project is a planet of one red-dwarf system.

## What is what

| You see | It means |
| --- | --- |
| The red star in the middle | This computer. Every agent the hub watches runs on it. Decoration. |
| A planet | One project. Its kind (lava, desert, ocean, rocky, ringed giant, gas giant, ice giant, barren) is stable for that project |
| The planet's tint | The project's own colour |
| A green moon | One working agent (at most five are drawn) |
| An amber moon and an expanding ring | Something is waiting for you |
| A dark planet with no moons | A resting project |
| A white ring and "YOU ARE HERE" | The project you are in |
| Flares on the star | More often when more agents work across all projects |

Planets are tidally locked: the same face always looks at the star, and the night side shows city lights while the
project works.

## Moving around
- Click a planet, or a project in the rail, to fly down into its hall.
- `G` flies down into the current project. `R` returns to the overview.
- Orbits follow a project's place in the list, so a project keeps its orbit as long as the list does not change.

## Settings that change it
The sky theme (Deep space, Nebula, Aurora planet) tints the star's glow and the light on the planets.

## Honest limits
The star, the orbits and the planet surfaces are decoration. The moons and the flare rate come from the real crew.
